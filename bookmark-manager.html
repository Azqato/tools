Bookmark Manager

Import the bookmarks file your browser exports, rename and tidy them, then export it back. Folders are kept intact. Nothing is uploaded.

Your collection is stored in this browser only. Clearing your browser data removes it, and it does not follow you to another device, so export a copy if it matters. Export produces the same format your browser imports, so the file works in Chrome, Firefox, Safari and Edge alike.
